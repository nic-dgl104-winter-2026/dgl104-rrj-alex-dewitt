

# WEEK 12

## Project Progress and Planning

This week I am just starting my coding project.

For my project, I building a Smart Task Management System. The main idea is to let users create, assign, and manage tasks with things like due dates, priority levels, and status tracking.

### Chosen Language

I decide to use:
- HTML
- CSS
- JavaScript

I chose these because they are what I am most comfortable with right now, and I know I can actually finish a working project using them. Instead of trying to learn a completely new backend language like Node.js, I think it is better to build a solid front end project that works well.

For storing data, I am planning to use localStorage as a simple solution so tasks can still be saved and loaded.

### Initial Ideas

Some of the features I plan to include:
- Create, edit, and delete tasks
- Assign tasks to a user
- Set due dates and priorities
- Track task status (To Do, In Progress, Completed)

I am also thinking of adding a simple smart feature where the app suggests a priority level based on how close the due date is. For example:
- Due very soon = High priority
- A few days away = Medium
- Later = Low

### Approach

My main goal right now is to:
- get the basic structure working first
- make sure functionality works properly
- then improve the UI and add extra features after

I also plan to organize my code clearly so it is easier to maintain and explain later, especially when connecting it to stuff like OOP and design patterns.
