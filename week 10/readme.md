

# WEEK 10

### Activities
- Reviewed contribution guidelines of an open source project
- Read README, CONTRIBUTING.md, and CODE_OF_CONDUCT.md
- Selected a beginner-friendly project (Learn Git)
- Forked the repository and explored its structure
- Made a small contribution by editing the CONTRIBUTORS.md file
- Created a commit and (optionally) a pull request

### Learning
This week helped me understand how open source contributions actually work in practice. I learned how to fork repositories, create branches, and make changes without affecting the original project. Also most of the stuff I did is written in the CONTRIBUTING.md file.

I also learned that contributions are not limited to coding, and that improving documentation is also valuable.

### Challenges
Understanding the full workflow of contributing was challenging at first, especially making sure I followed the correct steps.

### Reflection
This experience made me more confident using GitHub and showed me how real-world development works.
